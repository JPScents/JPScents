## Commands and scope

| Label                         | Command and coverage                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Architecture**              | `npm run architecture:check`. Checks feature layout and public entry points, recognised dependency and Prisma boundaries, feature cycles, source parsing, and suppression scope. The same command already runs inside `npm run check`. A direct feature-directory argument to the checker runs only that feature's structure and Prisma checks. [Checker](../../.agents/skills/feature-structure/scripts/check-structure.mjs) · [Package scripts](../../package.json#L19) |
| **Checker fixtures**          | `npm test -- tests/architecture/feature-structure.test.ts`. Tests invoke the CLI in disposable trees and assert its exit status and diagnostics. [Fixtures](../../tests/architecture/feature-structure.test.ts)                                                                                                                                                                                                                                                           |
| **Lint, format, types**       | `npm run lint`, `npm run format:check`, and `npm run typecheck`. These use the existing ESLint configuration, Prettier, and strict TypeScript. [ESLint](../../eslint.config.mjs) · [Prettier](../../.prettierrc.json) · [TypeScript](../../tsconfig.json)                                                                                                                                                                                                                 |
| **Tests**                     | `npm test` or `npm test -- <test-path>`. The current suite uses Vitest and jsdom where applicable. Tests that mock Prisma, Supabase, or framework boundaries provide evidence for the exercised behaviour. [Vitest](../../vitest.config.ts) · [Tests](../../tests)                                                                                                                                                                                                        |
| **Isolated runtime evidence** | `npm run build` and `npm run db:validate` are existing commands. Use the documented isolated path. Run affected browser, Auth, Storage, and migrated-database cases under VER-02. The existing suite has no command that supplies all this evidence. [Safe verification](../../README.md#agent-verification-without-secret-file-access) · [ADR-0004](../architecture/adr/0004-merge-and-release-verification.md)                                                          |

The status column classifies the primary mechanism. **Already Enforced** and **New Deterministic Check** refer to the stated coverage only. **Test/Integration Required** and **Review Required** describe evidence still needed. **Not Yet Enforceable** identifies a gate with no verified automatic execution. The coverage column states the limits for each rule.

## Suppression scope

The checker accepts one line-scoped `@next/next/no-img-element` directive at each of the two approved images. It verifies the asset map, local import, decorative alt text and the visible label inside the expected control. Stage A removes the file-wide GAP-006 allowances. Fixtures cover valid relocated elements, blanket and inline overrides, changed artwork and expanded scope.
